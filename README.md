# Планировщик — веб-версия для iPhone

Открыть: **https://ruleownfreedom.github.io/planernaroda/**

Установка на iPhone: открыть ссылку в **Safari** → кнопка «Поделиться» → **«На экран «Домой»»** → «Добавить».
Приложение откроется без адресной строки, со своей иконкой, и работает без интернета после первого открытия.

- Данные хранятся только в этом iPhone, внутри веб-приложения (отдельно от вкладки Safari и от Android-версии).
  Переносить их — через экспорт/импорт в настройках приложения.
- На iPhone не работают: вибрация, вложения и сохранение файлов через Android, смена иконки.

## Как обновляется

Репозиторий обновляется по команде «обнови файлы» вместе с Android-версией (ruleownfreedom/planer):

```
python3 tools/build_index.py planer.html   # HTML артефакта «2509» → index.html с дополнениями для iPhone
git commit -am "Версия …" && git push      # GitHub Pages публикует за 1–2 минуты
```

`tools/build_index.py` не меняет код приложения — только добавляет в `<head>` мета-теги iOS, иконку,
манифест, непрозрачный статус-бар и офлайн-кэш (`sw.js`). Иконки (`tools/render_icons.py`) нарисованы из иконки
темы «Сталь и хром» и перерисовываются только если она изменится.

Если после обновления внизу экрана пустая полоса — удалите значок с экрана «Домой» и добавьте заново: iOS читает настройки статус-бара только при добавлении.
